# Dotfiles

Prepending a dot into a name of a file or directory prompts various software like shells and file managers to hide it from view, hence "dotfiles". Many programs save their state and configuration into these dotfiles.

This repository is a personal collection of dotfiles for programs I use.

## Chezmoi

This repository uses [Chezmoi][chezmoi] to place dotfiles into their appropriate locations in the `$HOME` directory.
